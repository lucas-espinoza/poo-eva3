Viajes Aventura:
gestión de paquetes y reservas.

Aplicación web académica para centralizar la operación turística y el proceso de reserva.

02 · Antes y después de la aplicación

De planillas aisladas
a una operación centralizada.

El sistema reduce trabajo manual y entrega al equipo una fuente única de información para administrar el servicio.

Antes: Excel y revisión manual

Información distribuida, actualización repetida de cupos y mayor posibilidad de inconsistencias.

Ahora: datos centralizados

Destinos, paquetes, clientes y reservas quedan relacionados y disponibles para el equipo.

Resultado: control y trazabilidad

Se registra el precio reservado, se controlan cupos y cada solicitud mantiene su estado.

Crear paquete→Publicar→Reservar→Validar pago

03 · Tecnologías aplicadas

Una solución web construida
para reglas de negocio reales.

Python + Django

Backend con modelos, vistas, formularios, autenticación y validaciones de las reglas de negocio.

SQLite + persistencia

Base de datos relacional local para clientes, destinos, paquetes y reservas entre ejecuciones.

POO + interfaz web

Entidades y servicios separados por responsabilidad; HTML y CSS para las vistas de cliente y administración.

La IA generativa se utilizó como apoyo para ideación, redacción y diseño; las validaciones de cupos, precios y estados corresponden a lógica propia implementada en Python.
